# 基于图文对齐的合成验证码视觉定位与点击轨迹生成

## 1. 项目背景

经典人机验证任务通常要求用户根据自然语言提示，在图像中定位指定目标并完成点击或拖拽操作。本项目不针对真实网站验证码或安全系统，而是构建一个合成的 9 宫格验证环境，用于研究多模态数据处理中的图文对齐、视觉定位和交互轨迹生成问题。

## 2. 任务定义

输入：

- 一张 9 宫格验证图像；
- 一条中文任务描述，例如“请点击青色汽车”。

输出：

- 目标格子编号；
- 目标点击坐标；
- 一条从起点移动到目标位置的鼠标轨迹。

## 3. 数据集构造

项目使用程序自动生成合成数据集。每张图片大小固定，划分为 3x3 网格。每个格子中绘制一个彩色对象，对象类别包括消防栓、汽车、自行车、路灯、树、信号灯、房子、星星和旗帜。颜色包括红色、蓝色、绿色、黄色、紫色、橙色、粉色、青色和黑色。

默认生成的图像中不包含文字标签，任务描述和监督标签只保存在 `manifest.jsonl` 中。为了便于人工检查，数据生成脚本提供 `--debug-labels` 参数，可选择性地在格子中绘制文字标签。

数据集支持三档难度：

- easy：每张图中 9 个格子的颜色唯一，指令包含颜色和物体类别；
- medium：颜色会重复，物体类别唯一，指令包含颜色和物体类别；
- hard：物体类别唯一，指令只包含物体类别。

## 4. 方法设计

### 4.1 规则颜色基线

规则颜色基线用于提供简单可解释的对照：

1. 从中文任务描述中解析目标颜色；
2. 对图像中每个格子计算像素级颜色匹配分数；
3. 选择与目标颜色最匹配的格子作为预测结果；
4. 根据预测格子中心生成鼠标轨迹。

该方法在 easy 难度下表现很好，但在颜色重复或不提供颜色提示时会明显下降。

### 4.2 模板图文匹配模型

模板图文匹配模型是当前主展示方法：

1. 从中文任务描述中解析颜色和物体类别；
2. 图像侧对每个格子提取颜色匹配分数；
3. 对目标物体类别生成形状模板；
4. 计算每个格子与目标模板的前景掩码相似度；
5. 融合颜色和形状得分，输出目标格子概率。

该方法比单纯颜色基线更接近“图文条件 + 视觉特征对齐”的流程，可以处理 medium 和 hard 难度。

### 4.3 神经模型基线

神经模型用于展示可训练多模态定位框架。升级后的照片模型使用对象感知结构：

1. 文本侧使用字符级词向量和双向 GRU 编码任务描述；
2. 图像侧将每个格子裁剪出来，使用 CNN 提取局部照片特征；
3. 将文本特征与 9 个格子的图像特征融合；
4. 输出 9 个格子的目标概率；
5. 训练时增加每格物体类别分类辅助损失，使图像编码器学习“每个格子是什么物体”。

当前模型仍然较轻量，但已经可以在真实照片九宫格上获得明显优于随机的结果。后续可以继续替换为 ResNet、ViT、CLIP 或 Cross-Attention 模型。

## 5. 评估指标

项目提供 `scripts/evaluate.py` 进行批量评估，指标包括：

- Grid Accuracy：预测格子是否正确；
- Top-3 Accuracy：真实目标是否出现在概率最高的 3 个格子中；
- Mean Click Distance：预测点击点与真实点击点之间的平均距离；
- Median Click Distance：点击距离中位数；
- Failure Cases：保存失败案例图，红框为预测，绿框为真值。

## 6. 当前实验结果

在各难度数据集上，按 85% / 15% 划分训练集和验证集。600 条样本时验证集共有 90 条样本；快速难度对比使用 120 条样本，验证集共有 18 条样本。

| 数据难度 | 方法 | Accuracy | Top-3 Accuracy | Mean Click Distance |
| --- | --- | ---: | ---: | ---: |
| easy | 规则颜色基线 | 1.000 | 1.000 | 0.000 |
| easy | 模板图文匹配模型 | 1.000 | 1.000 | 0.000 |
| medium | 规则颜色基线 | 0.333 | 1.000 | 70.960 |
| medium | 模板图文匹配模型 | 1.000 | 1.000 | 0.000 |
| hard | 规则颜色基线 | 0.111 | 0.333 | 108.423 |
| hard | 模板图文匹配模型 | 1.000 | 1.000 | 0.000 |
| 默认 medium 600 样本 | 规则颜色基线 | 0.433 | 1.000 | 56.632 |
| 默认 medium 600 样本 | 模板图文匹配模型 | 1.000 | 1.000 | 0.000 |
| 真实照片 500 样本 | 对象感知 CNN 模型 | 0.773 | 0.960 | 32.248 |
| 真实照片 500 样本 | 残差 CNN + 数据增强短训 | 0.333 | 0.680 | 108.796 |

结果表明，当颜色唯一时，简单颜色基线即可完成任务；当颜色重复或文本中不包含颜色时，颜色基线显著下降。模板图文匹配模型引入了物体形状匹配，因此可以稳定完成合成数据的 medium 和 hard 难度。在真实照片九宫格上，原始轻量模型准确率约为 0.044；升级为对象感知 CNN 并加入物体类别辅助监督后，准确率提升到 0.773。残差 CNN 与数据增强版本更偏泛化训练，短训结果较低，需要更多 epoch 和更多真实照片才能体现优势。

当前项目保留两条训练路线：

- 快速展示路线：对象感知 CNN，训练较快，当前 checkpoint 表现最好；
- 泛化实验路线：残差 CNN + 数据增强 + 最佳 checkpoint/早停，适合扩容数据后长训。

## 7. 可视化与演示

运行以下命令启动交互式 Demo：

```bash
streamlit run app.py
```

页面支持切换“模板图文模型”“规则颜色基线”和“神经模型”，展示任务文本、预测格子、概率分布和鼠标轨迹。

## 8. 局限性

当前项目仍有以下局限：

- 数据是合成图形，与真实复杂图像存在差距；
- 模板图文匹配依赖合成图形的固定绘制规则，泛化到真实图片仍需更强模型；
- 神经模型还没有充分利用对象形状和类别信息；
- 当前只支持单目标点击任务，尚未支持多目标选择、滑块、旋转或顺序点击。

## 9. 后续工作

后续可以从以下方向扩展：

1. 引入 CNN、ResNet18、ViT 或 CLIP 作为图像编码器；
2. 使用 Cross-Attention 实现更明确的图文对齐；
3. 支持多目标选择任务，例如“请选择所有树”；
4. 支持空间关系任务，例如“请点击红色汽车右边的物体”；
5. 加入遮挡、旋转、缩放、噪声和真实图片背景；
6. 收集或模拟真实鼠标轨迹，训练轨迹生成模型。
